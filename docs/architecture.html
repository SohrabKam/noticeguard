NoticeGuard Architecture

Subcontract payment compliance for UK main contractors · Next.js + Clerk + Inngest + Neon

Request Flow

  • • Browser → proxy.ts (Clerk auth guard)
  • • Server Component → requireOrg() → Prisma
  • • Server Action → requireOrgAction(role) → DB
  • • API route → requireOrgRoute() or requireApiKey()
  • • Every path scoped by organisationId

Background Jobs

  • • deadlineSweep — hourly, breached/urgent alerts
  • • missedApplicationSweep — hourly
  • • retentionReleaseSweep — daily, TZ=Europe/London
  • • documentExpirySweep — daily
  • • dailyDigestSweep — daily summary email

Data Model

  • • Organisation → Projects → SubcontractOrders
  • • SubcontractOrder → PaymentSchedule → Cycles
  • • Cycle → Application → Assessment → Notices
  • • ApplicationLine · AssessmentLine (per-BOQ-row)
  • • RetentionLedger · AuditEvent · ComplianceDoc
